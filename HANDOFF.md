# Magmafy Pro: handoff for the next Claude

Last updated 2026-10-28. Read this before you touch the site.

## What it is

A new website for **Magmafy**, Tarek Mahfouz's agency: AI marketing, content, ads and websites for **furniture shops and showrooms in Saudi Arabia**. It copies the structure, strategy and modules of the TMX AI site (`/mnt/project-files/tmx-ai`, German and English) and rebuilds them in Magmafy's look, policy and audience.

- **Languages:** Arabic (default, RTL) and English only. Arabic uses Western digits. Money is shown as `N ر.س` in Arabic and `SAR N` in English.
- **Palette:** `#feda75 → #fa7e1e → #d62976 → #962fbf → #4f5bd5` on a dark background, `#0e0716`. Taken from the old Magmafy site (`/mnt/project-files/magmafy-3d`).
- **Fonts (local):** El Messiri for headings, Tajawal for body text.
- **Standing rule:** every site has **"Made by Magmafy"** at the very bottom of the footer. Every page has it (`.footer__made`).

## Run it

```
cd magmafy-pro
python -m http.server 8080      # then open http://localhost:8080
```

Opening `index.html` by double-click does not work, because ES modules and the GLB models need a server. Add `?lang=en` or `?lang=ar` to force a language.

## Tech

- Static vanilla JS with ES modules and **no build step**. Vendored libraries are in `assets/vendor` (three.js, GLTFLoader, GSAP, ScrollTrigger).
- **Strict CSP** is set in a meta tag on every page: `script-src 'self'`, `require-trusted-types-for 'script'`, and `connect-src 'self' blob: https://api.web3forms.com`. The `blob:` entry is needed for GLTF textures.
  - **Never use `innerHTML`.** Build all DOM with `h()` from `assets/js/core.js`.
  - No inline scripts and no third-party requests on load.
- **Content:** all copy is in `content/site-content.js` as `window.MG_CONTENT = {...}`, with an `i18n.ar` and `i18n.en` tree plus settings, legal and projects.
  - The file was generated by `magmafy-pro-tools/build_content.py` from `content_ar.py` and `content_en.py`.
  - **Warning:** running the generator overwrites any edits made through the admin. Either edit the `.py` sources and regenerate, or edit the `.js` directly, but not both.
- **HTML pages** are generated by `build_html.py`, which holds the shared head and CSP. If you change the CSP, change it there too.

### Main JS files (`assets/js/`)

| File | What it does |
|---|---|
| `core.js` | `h()`, i18n `t()`, `money()`, the language switch and RTL handling |
| `layout.js` | Header (the desktop nav hides "contact" because the header CTA already books) and the footer with "Made by Magmafy" |
| `world.js` | three.js particle "volcano" world. Sections change its shape with the `mg:scene` event |
| `main.js` | Boot, GSAP and ScrollTrigger reveals (guarded when there is no `[data-reveal]`), and the portfolio stage pin (`[data-pf-stage]`) |
| `journey.js` | Home "client journey" demo, using `jx-*` classes |
| `showcase.js` | Home covers: showroom, ads and social (`sc-*`) |
| `portfolio.js` | 9 projects in a pinned stage: story campaign, market report, comment automation, shop-the-look, growth dashboard, White Friday landing page and covers |
| `booking.js` | Booking flow: type (market research, website scope or general consultation), Google Meet or Zoom, then day and time. **Friday is off; Saturday is open.** Sends through Web3Forms, falling back to mailto. Reads `?topic=research\|website\|general` |
| `consent.js` | Cookie and consent banner, stored in localStorage under `mg-consent` |
| `pages.js` | Service pages load their demos with `import('./demos/<page>.js')` and call `mount()` |

### Demos (`assets/js/demos/`)

| File | Demos |
|---|---|
| `research.js` | City market scan, mystery shopper, personas, the Saudi seasons calendar (Nov 2026 to Oct 2027) and a roadmap |
| `content.js` | AI studio before and after, content calendar, media and budget planner, report |
| `websites.js` | **3D sofa configurator** (`sofa3d.js`: fabrics, legs and rooms; it loads lazily and takes a few seconds), a design carousel and the scope calculator |

| `consulting.js` | Session types, a readiness quiz with a radar chart, and a customer-leak gauge |

### CSS

`main.css` and `demos.css` are the TMX base. **`magma.css` is the Magmafy layer**: the palette, Arabic and RTL rules, and every new component. Add changes to `magma.css`.

- An offline mode downloads the edited file instead of committing it.
